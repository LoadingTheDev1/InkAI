Before you start

  • Write every letter on the dark line. Tails of g, j, p, q and y hang below it.
  • The faint letter in each box only shows how big to write. Don't trace it or copy its shape. Write the letter the way you normally would.
  • Make each copy a little different, just like real handwriting. That's what makes the result look real.
  • If your handwriting is joined up, include the little connecting strokes at the start and end of each letter.

Last step: spacing

Write this sentence the way you normally would

This teaches the gaps between your letters and words. Write each half on its own line.
